# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful and constructive. Harassment, discrimination and personal attacks
are not tolerated. Instances of unacceptable behavior can be reported privately
via GitHub (a private security advisory or a message to the maintainer
[@afry23](https://github.com/afry23)). The maintainer will review and respond
to all reports.
